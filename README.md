# CISO

A Chief Information Security Officer (CISO) resource and tooling repository.

## Overview

This project provides resources, tools, and frameworks for information security management and governance.

## Getting Started

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd ciso
pip install -r requirements.txt
```

### Telegram Bot Setup

1. Talk to [@BotFather](https://t.me/BotFather) on Telegram and create a new bot with `/newbot`
2. Copy the token you receive
3. Create a `.env` file from the example:
   ```bash
   cp .env.example .env
   ```
4. Paste your token into `.env`
5. Run the bot:
   ```bash
   python bot.py
   ```
